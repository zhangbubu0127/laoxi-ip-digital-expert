# 直播稿清洗工作流

把席校长直播逐字稿清洗成结构化知识沉淀（语言风格/内容口径/直播语料/家长问题带应答），为内容创作（选题/写稿/审核）打基础。

## 链路位置

清洗是知识入库的「前一步」，与 knowledge/ 事实层（只读）分离：

```
原始直播稿 ──▶ 清洗工作流（本目录）──▶ knowledge/ 沉淀 ──▶ 专家写稿/审核引用
  docx/txt        去重 + 4类提取           事实层文件
```

## 目录结构

| 文件/目录 | 作用 |
|---|---|
| `处理规范.md` | 直播稿清洗规则（处理前必读），定制直播 4 类 schema |
| `原始稿/` | 原始逐字稿 txt 存档，命名 `日期-直播主题.txt` |
| `产出/` | 清洗处理记录，命名 `处理记录-YYYY-MM-DD.md` |

## 处理流程

1. 原始 docx/txt → 提取纯文本 → 存 `原始稿/`
2. 按 `处理规范.md` 4 类提取（语言风格/内容口径/直播语料/家长问题带应答）
3. 内容事实与 `knowledge/业务事实/` 现有文件核对去重，差异才记
4. 4 类沉淀写入 `knowledge/` 对应目录
5. 补写 `产出/处理记录-YYYY-MM-DD.md`（处理清单/去重结论/统计）

## 沉淀去向（knowledge/）

| 类别 | 去向 |
|---|---|
| 语言风格 | `knowledge/人设/老席直播语言风格.md` |
| 内容口径 | `knowledge/业务事实/直播口径.md` |
| 直播语料 | `knowledge/直播语料/<日期-主题>直播语料.md` |
| 家长问题 | `knowledge/家长画像/直播问题库.md` |

## 命名与清理

- 原始稿：`YYYY-MM-DD-直播主题.txt`，不覆盖历史
- 处理记录：`处理记录-YYYY-MM-DD.md`，一天一份
- 知识沉淀只追加修正，不删历史
