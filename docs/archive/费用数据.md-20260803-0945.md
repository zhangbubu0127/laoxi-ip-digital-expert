# 费用数据

> 来源：老席新加坡项目PPT详解 + 项目深度说明文档 + 招生简章 + 老席书籍
> 更新：2026-05-22

## 项目费用

- **定向培养项目费**：21.98万（含国内1年学费 + 新加坡2年境外服务费）
- **包含服务**：留学规划、签证申请、接机、住宿安排、入学注册、体检、境外课业辅导（课件翻译+重点标注+免费补课）、申诉补考（2000新币/门由项目承担）、生活管理
- **不额外收费**：文书、签证、境外服务均含在项目费内

## 各阶段费用拆解

| 阶段 | 费用 |
|------|------|

| **三年本科总计** | **约65万**（建议家庭准备70-80万更宽裕） |
| 硕士1年（可选） | 约35万 |
| **本硕连读四年总计** | **约100万** |

## 生活费细节（新加坡）

| 类别 | 费用 | 说明 |
|------|------|------|
| 食 | 一顿20-30元 | 食阁为主，政府补贴；海底捞人均250元 |
| 住（自持公寓） | 5000-6000元/月 | 市场价1-2万/月，自持200套"老习之家"降费，三年省15-20万 |
| 行 | 约80新币/月 | 地铁0.8-3新币/次；打车贵 |
| 衣 | 极低 | 热带雨林气候，五件短袖+两件外套+三四双鞋过一年 |

## 合规备注

- 费用数字以此文件为准，定期核对最新报价
- 文案中可拆成小数字（"住宿费五千"而非"三年65万"），降低家长心理门槛
- 1980元体验包可全额抵扣留学项目费
- 不虚构价格：不说"5.8万包毕业"等低价噱头
