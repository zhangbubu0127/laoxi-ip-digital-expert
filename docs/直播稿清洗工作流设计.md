## 背景与目标

老席留学ip数字专家 知识库需要「直播稿数据清洗能力」。把席校长直播逐字稿清洗成 **4 类知识沉淀**，为内容创作（选题/写稿/审核）打基础：

1. 语言风格（实战印证）
2. 内容口径（对内容创作有用的事实讲法）
3. 直播语料（可引用的原话语料）
4. 家长问题（带席老师应答）

## 链路位置

清洗是知识入库的「前一步」，与知识沉淀（只读）分离，能力不混淆：

```
原始直播稿 ──▶ 清洗工作流（独立环节）──▶ knowledge/ 沉淀 ──▶ 专家写稿/审核引用
  docx/txt      处理规范 + 去重提取         4类事实层文件
```

## 目录结构（知识库内新增）


## 4 类沉淀去向与 schema

### 1. 语言风格 → `knowledge/人设/老席直播语言风格.md`

- 每条：**特征 + 直播原话例句 + 使用场景**
- 分类：口头禅、指令式互动 CTA（打一波X/拍完回打谢谢习校长）、身份背书句式、反复重讲循环结构、数字对比/排比、反常识钩子、人设自嘲话术
- 与「创作要求会纪要」（老席对编导的**要求**）互为补充：纪要是要求，本文档是**实战印证**

### 2. 内容口径 → `knowledge/业务事实/直播口径.md`

- 每条：**事实点 + 直播讲法 + 与现有档案的差异备注**
- 覆盖主题：项目定义/学制/年龄线/费用/入学门槛/毕业保障/学历认证/就业薪资/院校对标/市场数据
- 不设「直播专用」框，按对内容创作的价值组织，全团队可查
- 与现有 `业务事实/` 文件（项目详情/费用数据等）核对去重，差异才记

### 3. 直播语料 → `knowledge/直播语料/6月14日直播语料.md`

- 按叙事功能切块的可引用语料
- 每条：**原话 + 功能标签 + 来源时间点**
- 功能分类：开场互动/拉预期/讲项目/讲费用/处理反对意见/催单CTA/收尾

### 4. 家长问题 → `knowledge/家长画像/直播问题库.md`

- 公屏家长问题，**带席老师应答**
- 每条：**问题 + 席老师应答 + 类型标签 + 来源时间点**
- 与「家长原话库」（闭门会真实连麦）区分来源：公屏 vs 连麦
- 供选题钩子弹药：优先用「质疑型原话」做反常识劝退开头

## 处理规范要点

- **输入**：直播逐字稿（docx/txt，带说话人+时间戳）
- **清洗**：
  - 去噪：电流声/设备调试/团队杂话/无意义重复
  - 去重：同一话术直播循环 N 遍 → 只留最优版本 + 记录变体
  - 口语还原：指代不清的补全成完整句子
- **提取**：按 4 类规则提取，每条带追溯元数据（来源稿件/日期/时间点）
- **去重**：内容事实与现有 `业务事实/` 文件核对，差异才记
- **输出**：4 类沉淀 + 中间卡片
