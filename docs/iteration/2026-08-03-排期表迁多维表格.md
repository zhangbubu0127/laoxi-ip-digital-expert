## 目标

排期表具体到日期+发布时间；出选题后老板选定，主控同步到飞书多维表格；回执附表格链接。

## 改动清单

- `src/brain/scheduler.py`：8 字段（加 发布时间，默认 12:00）+ `set_base_sync` seam，三个写操作（add_entry/mark_published/record_data）后 `_sync(rows)` 镜像。
- `src/skin/base_bridge.py`（新建）：`base_url()` / `sync_rows()`；`_records_to_keymap` 适配 lark-cli record-list 的平行数组结构（data 值二维数组 + fields 列名 + record_id_list），按「日期+选题」建 record_id 映射，有 id 则 update 否则 create。
- `src/skin/lark_bridge.py`：run_loop 注入 `scheduler.set_base_sync(base_bridge.sync_rows)` + `controller.set_base_url(base_bridge.base_url())`。
- `src/brain/controller.py`：排期日期/时间解析（下周→具体日期、HH:MM）、`_try_pick_topic`（「排上第1个/定了这个」从席小题上一条产出定位选题入表）、`set_base_url`/`_base_link`（改排期回执附链接）。
- `src/brain/intent.py`：改排期触发词增「排上/排一下/定了」。
