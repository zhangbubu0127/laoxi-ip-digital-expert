# 迭代记录：小席接话 + 专家对话化 + 去标签

日期：2026-08-03

## 目标

解决「只能回答固定问题 / 没沟通能力 / 回答带【席小文】前缀很乱」的体验问题：
1. 小席对未识别成派单/操作的含糊消息，用 LLM 自然接话，不再回固定菜单。
2. 专家产出像人话：席小核先给白话审核结论再附 JSON 明细。
3. 真多bot 模式下各 bot 账号即身份，去掉回复里的「【角色】」前缀。

## 改动清单

- `src/brain/controller.py`：`_chat_generate` seam（默认 LLM）+ `_chat_reply`；「其他」意图改走 LLM 接话，失败降级原模板；修复看排期表漏附多维表格链接。
- `src/brain/experts/xiaone.py`：输出改「【审核结论】白话段 + 一行 JSON」。
- 5 个专家 prompt（xiaoti/xiaowen/xiaone/xiaoxi/fupan）统一加「输出不要带【席小X】自我标注前缀」。
- `src/skin/multi_main.py`：专家回复 `_tag`（加前缀）→ `_strip_self_tag`（去前缀）。
- `src/pipe.py`：`format_outbound` 去掉「【agent_tag】」前缀（显示层；会话记忆 render_history 的【speaker】前缀保留，供意图识别用）。

## 架构影响

- 显示层去标签，内部上下文（render_history / 会话记忆）保留 speaker 标签——不破坏意图识别与专家指代理解。
- 大脑层仍走注入 seam（`_chat_generate` 可测试替换）。

## 验证

- 全量 140 用例绿（14 模块）。新增：test_chat_uses_llm_for_other_intent、test_chat_falls_back_when_llm_fails；test_pipe 改断言无前缀。
- 6 bot 进程重启加载新代码。

## 遗留

- 老板群里实测：问「多维表格在哪」应回含链接的排期表；闲聊应得到自然接话；专家回复不再带【角色】前缀。
