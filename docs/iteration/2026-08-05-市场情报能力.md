# 迭代记录：市场情报能力（竞对情报库 + 实时搜索 + 热点雷达接入）

日期：2026-08-05
关联：老板需求「席小题用 websearch 搜新加坡留学热门选题、竞对、竞对劣势当选题」→ 三个能力都要有 + 雷达接入 + 雷达迁入本仓库

## 目标

席小题出选题时，除了本地知识库，还能拿到「互联网上的市场热点 + 竞对及竞对劣势」，当选题原料做反常识劝退钩子；雷达每日热点自动同步进来，整个项目 GitHub 上传完整自包含。

## 改动清单

- `knowledge/竞对分析/`（新建）：README.md（文件所有权表：竞对图谱/中新教育对比=人工润色，热点话题/竞对线索=机器写）+ `竞对图谱.md`（WebSearch 真实竞对：新东方前途/启德/金吉列/新通/IDP 等，列「定位/主推卖点 | 与我们相比的劣势（选题钩子）| 出处」+ 行业通病 + 钩子角度）+ `中新教育对比.md`（GEP 二次机会/Full SBB/PSLE/DSA/IP 直通车等，家长原话）+ `热点话题.md`（机器覆盖更新）。
- `src/brain/market.py`（新建）：`search_web`（Bing RSS via requests + `_SG_WORDS` 相关性过滤，任何失败→[]）+ `hot_topics`/`competitor_leads` + `intel()`（拼【竞对情报】段，热点缺失/超 3 天 stale 时实时兜底标注「实时搜索·尽力而为」，永不 raise）+ `refresh()`（写热点话题.md 盖当日 + 竞对线索.md 原样存线索，不碰人工文件）。
- `scripts/sync_radar.py`（新建）：读 `radar/output/` 最新 `radar_YYYY-MM-DD.csv` → 生成 `knowledge/竞对分析/热点话题.md`；同目录 edu_compare.json 且目标不存在 → 生成中新教育对比.md 种子；`--dry-run`/`--radar-output`。
- `src/brain/experts/xiaoti.py`：_system() 素材库段后插【竞对情报/市场热点（选题原料）】段 + 默认立场补「借竞对/市场真实劣势做反常识钩子（不点名贬低）」。
- `src/brain/intent.py`：INTENTS 增「更新市场情报」+ LLM 提示词描述 + `_MARKET_HINTS` 关键词兜底。
- `src/brain/controller.py`：`_ADMIN_ONLY` 增「更新市场情报」；新增 `_refresh_market()`（成功回执热点/线索条数，失败回执「情报库保持上次数据」+ 提示雷达同步）。
- `radar/`（迁移）：整个新加坡热点雷达项目从外部目录 `mv` 进老席仓库根；`.gitignore` 补 radar 密钥/产出；`radar/CLAUDE.md` 目录约定改仓库内路径 + 每日流程补 step 4 同步席小题情报库。

## 架构影响

- 统一「市场情报库」：写入方两个（雷达同步 + 主控 refresh）、读取方一个（席小题 prompt 注入），大脑层只读 knowledge/，`market.py` 为唯一新模块、纯函数、永不 raise、超时严格。
- 实时搜索定位：**尽力而为补充层**，不是核心依赖。可靠主路径 = 雷达每日同步（机器可靠）+ Claude 会话 WebSearch 润色入库（人工可靠）。风控时静默回落情报库，不阻塞出题。
- 雷达迁入后 GitHub 上传自包含：run.py 位置无关，system python3 直跑（已装 requests/playwright），密钥/登录态/产出全 gitignore。

## 遗留

- 运行时 Bing RSS 实时搜索尽力而为；要「每次必实时」需付费搜索 API key（新依赖+密钥红线，另行决策）。
- 竞对图谱.md 首版为 WebSearch 润色入库；后续靠 `refresh()` 的竞对线索.md + 人工挑着更新（半自动）。
- 雷达每日更新仍须在雷达项目 Claude 会话里触发（run.py 的 WebSearch 层依赖 Claude，非纯 cron）；本迭代只接「同步」这一半。
