## 一、目标

## 三、架构影响

- 新增 4 个模块（rules/reflow/search/fupan+xiaoxi 专家），全走既有接缝模式：路径常量可重定向、verify/generate 可注入，测试免网络免 LLM。
- 熔断账本从「写盘」升级为「写盘+读盘」，`memory/token账本.md` 成为唯一事实来源，重启不丢。
- 外搜无搜索 API key、禁装全局依赖的约束下，选 Wikipedia API（免 key，stdlib）作为 v1；核不到事实走文档既有兜底「需老板确认 · 低置信度」。将来有 key 只换 `search.py` 内部实现，接口不变。
- 已确认规则注入席小文 prompt，学习闭环（学→确认→生产引用）成立。
