# 家长原话库

> 来源：老席闭门会议26份逐字稿（0-19号、年度大会、第一场/第二场）

## 八、连麦家长原话（完全还原）

**Alex Wong（深圳初三家长，2.txt）**：
> "我们在深圳，孩子今年初三，马上就要中考，预估就400来分左右。我跟我先生也觉得这个分数可能走国内要去读个好的高中然后上大学可能会比较艰难。其实我们自己也不想让孩子这么卷。我跟我先生都是做跨境贸易的，在国外也是有团队的，我们其实对我们孩子的定位还是非常明确的。第一个希望他把英语学好。第二个问题就是项目的一个合规性，因为这对我们非常非常重要——你们这边跟北京那边大学是一个什么样的关系？以及孩子走这条路回来之后做中留服认证的问题。"

**徐翔（上海初三家长，第二场6.txt）**：
> "我家孩子初三，今年9月份上初三。但是他就是喜欢打游戏，学习上面不是那个自觉太自律。他说如果这样我不去，就很抵触搜手机断网。因为他初二第二学期基本上都是在家没有好好的学。我们前面就是把他绷得太紧了——没有双休日。到初二第二学期他一下子爆发了，等于待在家里了。"

**听雨（高三家长，女儿，第二场6.txt）**：
> "他今年高三毕业。我最最担忧的就是他到北京来适不适应？然后能不能够在国外不适应。就是哪怕选择了以后，怕他要到时候那个适应不下来，跟不了。"

**旭东（山东家长，初三女儿，第一场8.txt）**：
> "今年刚刚初中毕业，如果是参加9月份的学习的话，在北京是在哪个学校学习？咱们这个项目都是SEAA项目嘛？是大学内部的项目吗？在官网上有招生吗？去到新加坡之后，咱们对应的大学...我看到新加坡大部分都是私立学校...有没有很明确的就是哪几个大学吗？"

```
"我们在新加坡当地都可以横着走路了。"
"我10,000%相信您。"（多次出现）

```

## 使用规则

1. 写选题钩子时，优先用"质疑型原话"做反常识劝退开头
2. 写正文时，用"恐惧型原话"做恐惧+方案开局的对立面
3. 写收口时，用"放心后原话"做社会证明
