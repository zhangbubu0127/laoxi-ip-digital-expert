# 直播问题库（公屏提问 · 带应答）

> 来源：2026-06-14 席校长直播公屏提问（清洗工作流 2026-08-02 处理）
> 与「家长原话库」区分：**本库=直播公屏提问**（短、零散、现场应答）；家长原话库=闭门会真实连麦（长、带背景）
> 用途：写选题钩子优先用这里的问题——席校长本人就是「把家长评论区问题搬到直播间」的高手（见`老席创作要求会纪要`3.6）
> 标注：`（待补充）` = 席校长现场答得含糊或未直接回答

---

## 一、门槛类

**Q：初一、初二，预算没问题，想留学，成绩一般，申请上的几率大吗？**
A：「我们这个路径是帮你孩子上到世界排名前100、前200大学，是一个确定性的结果，只要你能通过笔试、面试，就一定能走这个路径。」[37:08]
→ 写作价值：家长用「成绩一般」试探，席校长的回答是「不看分，看笔试面试」，这是反常识钩子素材。

**Q：我们家孩子今年考试100、200、300、400分，能走这个路径吗？**
A：成绩低没问题，路径面向「在国内大概率上不了重点高中、名牌大学」的孩子，核心只看能否通过笔试面试。[20:29-20:52]
→ 写作价值：「100-400分都能走」是低分段家长的强钩子。

**Q：毕业证书拿不到，去不了了吧？**
A：「哪个毕业证书？初中毕业还是啥呀？」（席校长反问确认，未展开回答）（待补充）[01:30:xx]

## 二、毕业类

**Q：英语不好能上吗？**
A：「英语不好的孩子不是因为他学习能力有问题，是因为他没有碰到好老师，你给我把他送来北京，我一年之后还给你一个不一样的孩子。这个世界上没有差学生，只有差老师。」[52:12]
→ 写作价值：「没有差学生只有差老师」是安抚+承诺双杀句式。

**Q：孩子不及格有救吗？**
A：先引导拍19.9元课，未直接作答（待补充）。[52:36]
→ 注意：席校长现场用成交引导代替了回答，写稿时应补上实质回答（如软着陆/助教兜底）。

**Q：孩子去了新加坡，英语授课，能毕业吗？**
A：全程陪跑到毕业。宽进严出，入学容易毕业难，但习校长团队带助教、管到毕业，13年2万学生无一毕不了业。[01:08:22]
→ 写作价值：这是「毕业恐惧」的核心应答，可拆成独立选题。

## 三、费用类

**Q：国内的是吗？费用多少？**
A：第一年国内，第二、三年在坡县，最后一年硕士自选。一年20万出头，三年本科65万。[19:xx]
→ 写作价值：「一年国内两年坡坡」+「65万含生活费」是费用锚点重复输出。

**Q：一年在北京住校吗？**
A：是的，住在学校内部，跟统招生享受同吃、同住、同泡图书馆、同住宿舍一模一样的待遇，拿一张学生卡。[53:02]
→ 写作价值：「跟统招生同待遇」是难得的具象卖点（985校园生活）。

## 四、路径类

**Q：国内有哪些学校可以报名？基地可以选吗？**
A：国内四所合作院校（清华/北大/北语/北交）定向培养一年。报2027年可选，2026年很难选——北语6个班满额、北大1个班满额。[11:15][13:08]
→ 写作价值：「2026年满额只能报2027」是稀缺感话术，也是真实报名状态。

**Q：高三毕业能去坡坡吗？**
A：可以。高三毕业走四年本硕连读，读世界前100、前200本科，硕士前50（南洋理工/国立等）。[01:16:xx]
→ 写作价值：高三家长最担心的「还能不能上车」，答案是可以但晚，引出「及时止损」。

**Q：怎么报名？**
A：「我先把这个项目给你介绍一下，我一会再说怎么报名。」[13:41]（流程性引导，未直接回答）
→ 写作价值：直播间的报名问题，真实运营话术是「先讲透再引导」。

**Q：能见您本人聊一下吗？**
A：「可以啊，过来呀，我线下的收费是19800一个小时，一对一咨询。」[06:12]
→ 写作价值：线下高客单背书，反向抬高端。

## 五、竞品/反对类

**Q：还在读国际学校（家长公屏反馈）**
A：「你赶紧去退去，你还读什么国际学校呀？国际学校上限不如公立学校高，国际学校下限比公立学校低。去不了第一梯队国际学校，第二梯队、第三梯队就是坑。」[24:04]
→ 写作价值：攻击国际学校的原话，是「劝退竞品」的现成弹药。

## 使用规则

1. 写选题钩子时，优先用「质疑/试探型」问题做反常识开头（成绩一般能上吗？100分能走吗？）
2. 写正文时，用「毕业恐惧」问题做恐惧+方案开局
3. 写收口时，用确定性承诺句式收尾（参照`直播语料`第七/八节）
4. 标`（待补充）`的问题，写稿前需向团队确认标准答案，不能空写
