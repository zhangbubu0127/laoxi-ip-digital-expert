## 关键引用约定

- **费用数字**：以 `业务事实/费用数据.md` 为准（项目费 21.98 万、三年本科约 65 万），写作/审核禁止随口编。
- **合规红线**：以 `合规红线/合规红线.md` 为准；席小核红线词须与之对齐（保证录取/包录取/国立大学直录/南洋理工直录 等）。
- **人设口吻**：自称「老席」、北方口语、反常识劝退钩子，见 `人设/老席创作要求会纪要.md`。
- **家长常问与成单解答**：`典型问题清单.md` 是席小题选题原料；8 分类成单解答是已成单顾问真实口径（席小文按选题分类引用）。**费用口径已于 2026-08-03 按录音修正**：21.98万=国内1年预科学费（含三年陪跑）、新加坡一年学费8-12万、三年七十多万，旧口径（65万/国内8万）已作废。
