# 家长典型问题清单

> 来源：《常见提问 - Sheet1.csv》典型问题，按 8 大分类组织
> 用途：席小题出选题时的选题原料——家长真正在意什么

## 路径与升学

1. 初中毕业真的能直接读大学吗？
2. 不需要读高中，学历会不会断档？影不影响考公考编？
3. 为什么要在国内读一年？直接去新加坡不好吗？
4. 国内这一年学什么？
5. 是在哪些学校上课？和这些学校是什么关系？
6. 是本校师资吗？不会是租的场地吧？
7. 北大和其他学校的区别是什么？
8. 医科工科也要读预科吗？
9. 国内一年预科结束后，能保证一定能去新加坡读本科吗？
10. 如果语言或预科没通过怎么办？
11. 我们最终能申请到哪些新加坡学校？
12. 是公立大学还是私立大学？
13. 能上南洋理工、新加坡国立大学吗？比例有多少？

## 学术与能力

1. 孩子英语特别差，国内一年时间能学会吗？
2. 能达到本科入学要求吗？
3. 我们需要提前学雅思吗？
4. 孩子没学高中知识，能跟得上、能听得懂国外的大学课程吗？
5. 项目是不是只适合成绩差的孩子？
6. 听说国外大学“宽进严出”，孩子能顺利毕业吗？
7. 项目有没有“包毕业”的保障？毕业率是多少？

## 学历与认证

1. 最后拿到的本科文凭，回国后教育部认可吗？
2. 能用来考公、考编、进国企吗？
3. 新加坡的私立大学是不是很“水”？含金量怎么样？
4. 和国内读的本科相比，找工作时有竞争力吗？

## 费用与价值

1. 一年20万够吗？网上不是说10万就够了？你们的总费用到底包含什么？后续还有额外收费吗？
2. 为什么国内读一年的费用这么高，甚至比在新加坡还贵？
3. 这个钱花得值不值？

## 安全与监管

1. 新加坡安全吗？
2. 孩子才初中毕业，年纪这么小，出去能适应吗？
3. 能陪读吗？
4. 孩子去了新加坡后，你们当地有人管吗？
5. “陪跑”具体是什么服务？能保证孩子的安全吗？
6. 听说国外乱，孩子会不会染上毒品或者被坏孩子欺负？
7. 离马来西亚那么近，会不会偷偷跑去玩不安全？

## 学生管理与适应性

1. 来你们这的都是什么样的孩子？
2. 会不会都是学习差的，把我孩子带坏了？有没有好学生？
3. 孩子性格内向/偏执/不听话，能适应国外生活吗？
4. 去了不学习、半途而废怎么办？
5. 国内这一年的学习氛围怎么样？
6. 孩子基础不太好，能跟上吗？

## 就业与发展

1. 本科毕业后，能在新加坡当地找到工作吗？
2. 留下来工作的概率高吗？
3. 回国后好找工作吗？能进什么样的企业？薪资水平如何？
4. 读完这个本科，能申请新加坡或者其他国家的硕士吗？
5. 比如南洋理工、国立的硕士？好申请吗？

## 信任与案例

1. 你们这个项目靠谱吗？做了多久了？是中介还是培训学校？
2. 你们和北语是什么关系？北语和新加坡是什么关系？
3. 你们每年招多少学生？有多少成功出去了？有没有已经毕业或就业的学生可以采访了解一下？能加在读学生微信聊聊吗？
4. 合同里能写“包入学、包毕业、包认证”吗？
5. 你们合同里为什么没有全程陪跑的具体内容，和直播间宣传的不一样
