# 竞对分析 · 目录约定

> 市场情报库：新加坡留学赛道「热点 + 竞对 + 中新教育对比」，给席小题出选题当原料。

## 文件分工

| 文件 | 谁写 | 刷新机制 |
|---|---|---|
| `竞对图谱.md` | 人工/Claude 会话润色 | 半自动：主控「更新市场情报」把实时线索写进 竞对线索.md，人工挑着并进本表 |
| `中新教育对比.md` | 人工/Claude 会话润色 | 种子来自雷达项目 edu_compare.json，后续人工维护 |
| `热点话题.md` | 机器覆盖 | 两个写入方：雷达跑完跑 `scripts/sync_radar.py`；主控「更新市场情报」→ market.refresh() |
| `竞对线索.md` | 机器追加 | market.refresh() 原样存实时搜索线索，供人工挑着润色 |

## 约定

- 席小题每次出选题由 `brain/market.py intel()` 读本目录并拼进 prompt。
- `热点话题.md` / `竞对线索.md` 是机器产物，手改会被覆盖；要人工加料请改 竞对图谱.md / 中新教育对比.md。
- 情报宁缺毋假：来源不明的「热度/劣势」标「待人工复核」，禁止编造。
