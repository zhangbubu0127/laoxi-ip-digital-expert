## 二、10条的内容分类学

### 类型A：真诚型（话题1/2/3）—— 信任基建

**特征**：不卖路径，卖人品。主动暴露"不赚的钱""劝退的人""行业的黑"。

**结构骨架**：
```
我的底线声明 → 分类列举（4类不收/3种黑心钱/砍价对比）→ 每一类配具体场景 → 行业对比（别人vs我）→ 价值观金句 → 轻CTA
```

**关键技法**：
- **主动劝退**建立信任：「我不收这类人」比「我适合你」信任感强10倍
- **具体数字**做信任锚：2000个劝退、13年、200套房源、EP8000新币
- **行业自黑**抢占道德高地：把同行的问题全说出来→观众自动把你归到"好人"阵营
- **签名式收口**：话题1「LX=良心」、话题2「把孩子送出去不是目的，让孩子拿到毕业证才是」、话题3「阳光下的良心钱」

**这是31条里完全没有的内容类型，也是老席区别于所有竞品的护城河。**

### 类型B：留学认知型（话题4/5/6/7）—— 世界观植入

**特征**：不直接卖新加坡，先重塑家长对"留学""高考""爱国"的底层认知。

**结构骨架**：
```
反常识观点抛出 → 数据论证现状残酷 → 推翻旧认知 → 新加坡作为新答案 → 数据轰炸 → 价值升华 → CTA
```

**四个认知锚点**：
- 话题4：与其被高考淘汰，不如淘汰高考（主动vs被动）
- 话题5：穷人版新加坡留学，一年20万（打破"留学=贵"的认知）
- 话题6：海南抢不走新加坡（消除替代焦虑）
- 话题7：越出国越爱国（化解"送出国=不爱国"的道德包袱）

**关键技法**：
- **先解决心理阻力，再推方案**：家长不报名不是因为不知道新加坡，是因为有顾虑（太贵？海南替代？不爱国？）
- **话题7是王炸级内容**：用希斯罗机场的细节故事代替说教，情感穿透力极强

### 类型C：留学科普型（话题8）—— 恐惧营销+服务证据

**特征**：用"踩坑后果"制造恐惧，用"我们怎么防"给出解决方案。

**结构骨架**：
```
恐怖警告 → 三类坑逐条拆解（国内思维vs新加坡法律）→ 每一条讲后果 → 别人不管vs我们管 → CTA
```

### 类型D：留学政策型（话题9/10）—— 数据权威+利益清单

**特征**：密集数据轰炸，把"新加坡留学的好处"拆成可感知的具体利益。

**结构骨架**：
```
定心丸（大环境判断）→ 逐条列举（6个专业/5类福利）→ 每条配具体数据 → 数字越细越可信 → CTA
```

## 五、给老席项目脚本产出的新规范

基于10条金牌文案，老席脚本产出优先级调整为：

**第一优先：真诚型（信任基建）**
- 劝退/不收/行业自黑类内容
- 每3-4条就要有一条真诚型
- 核心公式：底线声明 + 分类场景 + 行业对比 + 服务证据 + 价值观金句

**第二优先：留学认知型（世界观植入）**
- 先解决家长心理阻力，再推方案
- 选题方向：消除顾虑（太贵/不安全/替代方案/道德包袱）

**第三优先：政策/科普型（权威建设）**
- 密集数据，每条配具体数字
- PR、就业、回国福利等利益清单类

**第四优先：传统流量型（31条模式）**
- 反常识钩子+路径+CTA
- 用于拉新，但需要真诚型配合做信任转化
