## 二、31条脚本的共用框架

每一条都遵循同一骨架，无一例外：

```
钩子（1-2句） → 别人不行/别人不知道（打压替代选项） → 新加坡独有路径（抬高）→ 数据锚点轰炸（年龄/费用/时长）→ 结果画面（就业/学历/早挣钱）→ CTA
```

关键规律：
- **一定要打压替代选项**：31条中29条明确提到"别人不行"——日韩小语种难、德法毕业难、英美太贵、国内太卷
- **新加坡=唯一解**：每条都制造"全中国/全世界只有新加坡能这么干"的认知
- **不打击=不爆**：那2条没打压的（8和27，纯科普型），收藏高但转化低于有打压结构的

## 五、CTA规律（31条无一例外）

| CTA话术 | 出现次数 | 场景 |
|---------|---------|------|
| "打「新加坡留学」" | 11次 | 通用最强CTA |
| "打「我要」" | 6次 | 资料包引导 |
| "打「女生留学」" | 3次 | 女生专项 |
| "打「专业」" | 2次 | 就业/专业 |
| "打「捷径」" / "打「逆袭」" / "打「SEAA」" | 各1次 | 变体测试 |

规律：**CTA词越短越好，2-5个字**，"新加坡留学"五个字是验证过最高频的。

## 八、给各项目的选题优先级建议
