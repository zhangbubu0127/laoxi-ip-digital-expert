## 二、核心产品：初中毕业直升新加坡本科

### 产品名称
"新加坡管家式留学" / "北京985定向培养项目"

### 升学路径
```
15岁初中毕业
→ 国内1年（北京重点大学语言+预科）
→ 新加坡2年（本科）
→ 可选1年（硕士）= 20岁硕士毕业
```

### 入学条件
- 年满15周岁，有初中毕业证
- 雅思5.5分（完成率要求，≈高考英语90-100分）
- **不看中考成绩、不看高考成绩**
- 初二至高三均可申请（不需要读完高中）
- 年级匹配：初二→初三毕业后入学；初三→直接入学；高一/高二/高三→直接转轨

### 时间优势（核心卖点）
- 15岁入学 → 16-17岁国内预科 → 18岁起新加坡本科 → 19岁本科毕业 → 20岁硕士毕业
- **比国内常规路径（高中3年+本科4年+硕士3年=25岁硕士）提前5-6年进入就业市场**
- "国内同龄人刚上大一，你的孩子已经硕士毕业了"

### 费用结构（核心卖点）
| 阶段 | 费用 |
|------|------|
| 项目费（国内1年学费+新加坡2年境外服务费） | 21.98万 |
| 国内阶段（1年）学费+住宿费 | ~8万/年 |
| 新加坡阶段（2年）学费+生活费 | ~20万/年 |
| **三年本科总计** | **约65万**（建议家庭准备70-80万） |
| **四年本硕连读总计** | **约100万**（对标世界前100硕士） |

对比锚点：
- 英美澳加留学一年约70-90万 → 老席三年65万 = 别人一年的钱
- 新加坡其他中介约30-40万/年 → 老席20万/年（自持公寓降费）

省钱关键：团队自持200套学生公寓（"老习之家"），月住宿费5000-6000元，远低于市场1-2万/月，三年住宿省15-20万。

### 合作院校
- PSB学院：澳洲纽卡斯尔大学(QS227)、梅西大学(QS230)、英国考文垂大学(QS558)
- Kaplan高等教育学院：爱尔兰都柏林大学(QS118)、澳洲莫道克大学(QS423)、英国诺森比亚大学(QS550)、英国朴茨茅斯大学(QS635)
- 科廷大学新加坡校区、伯明翰大学(QS76)等

### 学历含金量
- QS世界排名前200，对标国内武汉大学(QS186)、哈尔滨工业大学(QS256)
- 中留服认证，全日制本科学历
- 回国可考公、考编、考研、进国企央企
- 上海留学生落户、军队文职招录的硬性门槛达标
- 已打31个市级公务员招考部门电话核实：学历认证完整，无"学历断档"风险

## 三、服务产品体系（三级产品矩阵）

### 第一级：钩子产品 — 49元直播课
- 定位：公域引流，建立初步信任
- 形式：抖音/视频号直播间付费课
- 内容：新加坡留学基础知识、教育体制解析、常见问题答疑

### 第二级：体验产品 — 1980元五重体验包
- 定位：双向筛选与深度链接（非盈利性质）
- 内容：
  1. 天赋测评（价值9800元）：联合中科院、北大耗资百万开发
  2. 不流通外教课（价值2000元/节）：团队专属外教，以朋友身份陪伴激发英语兴趣
  3. 北京名校探校（清华/北大/北语/北交四选一）：沉浸式体验名校氛围
  4. 笔试面试保录辅导：给予第二次笔试面试机会（正常仅一次）
  5. 14天新加坡微留学抵扣权：32800元微留学可抵扣1980元
- 如转报留学项目，1980元可全额抵扣学费

### 第三级：核心产品 — 21.98万管家式留学套餐

**国内阶段服务（1年）：**
- 北京985高校合作办学，在职在编教授授课
- 半军事化管理：上课收手机、随堂助教跟班、生活老师10点查寝
- 班主任每日鼓励式反馈，群内汇报学习生活情况
- 注重心理重建与自信重塑

**新加坡阶段服务（2年）— 八师护航体系：**
- 学术老师（1:30师生比，课前发PPT、课后答疑、作业批改、考前划重点）
- 生活管家（接机、住宿、体检、电话卡、家访）
- 宿管老师（日常查寝、卫生管理）
- 心理支持（情绪疏导、适应辅导）
- 保洁、医疗陪同等全方位支持
- 自持学生公寓（200套房源，大学官方认证宿舍）
- 50人境外团队全程陪伴

**核心承诺：**
- 所有服务包含在21.98万内，无额外收费
- 申诉补考费用（2000新币/门）由项目承担
- 课件翻译、重点标注、免费补课均不额外收费

### 第四级：延展产品 — 14天新加坡微留学（32800元）
- 12天大学校园沉浸式全英文学习 + 2天地标打卡
- 涵盖领导力、批判性思维等大学课程
- 利润极低（低于1000元），本质是引流与筛选产品

## 四、目标人群画像

### 核心画像
- 中国大陆，35-50岁，初二至高三（14-18岁）孩子家长
- 家庭年收入20-40万，中产阶层
- 孩子成绩中等偏下，不适应应试教育，有厌学/压抑倾向
- 共性：寻找"确定性"和"安全感"，对"信息差"极度敏感，需要可验证的社会证明，情感决策先于理性决策

### 四类决策角色

| 类型 | 占比 | 痛点 | 诉求 | 内容偏好 |
|------|------|------|------|---------|
| 焦虑型妈妈 | 55% | 怕考不上好学校、怕选错机构、怕出国不适应、怕费用不清、怕就业无门 | 清晰路径规划、机构实力证明、全程安全保障、透明费用表、就业数据 | 费用拆解、路径对比、成功案例、教育焦虑共鸣 |
| 务实型爸爸 | 15% | 怕投入无回报、怕被忽悠、怕决策错误 | ROI数据、行业真相、真实案例支撑 | 数据对比、费用分析、就业数据、回报率计算 |
| 迷茫型学生 | 20% | 怕融入不了、怕跟不上、怕选错方向 | 真实留学生活展示、逆袭可能性、专业指引 | vlog、学姐学长分享、校园实拍、日常生活 |
| 信息搜集型亲属 | 10% | 怕帮家人选错、怕信息不全 | 实用攻略、院校对比、政策汇总 | 攻略合集、避坑指南、权威背书 |

### 各年级成交特征
- **初三（主力）**：痛点最剧烈（考不上高中="没书读"），时间优势最显著，成交最多
- **高一/高二（次主力）**：厌学情绪爆发+国内升学无解，换赛道止损
- **初二（第三梯队）**：前瞻性布局+名额稀缺暗示，提前抢占北大40人定向班名额
- **高三（最少）**：路径优势减弱，竞品增多（中外合办、民办本科等）

## 六、内容创作三大主线

### 主线一：教育焦虑共鸣（前端获客）
- 切入点：中考分流焦虑、高中压力、亲子关系紧张、孩子丧失自信
- 创作形式：问题引发式（"你家孩子是不是...？"）、痛点场景还原
- 核心原则：以"理解焦虑"开场，而非"推销解决方案"

### 主线二：项目价值传递（中端转化）
- 切入点：教育体制合法性、管毕业vs管入学的本质区别、费用透明化
- 核心原则：传递三个核心价值 → 安全性（有人管有人陪）、确定性（毕业率99%）、性价比（三年65万）

### 主线三：真实案例见证（后端信任）
- 切入点：特定学生从"学渣到名校"的完整蜕变
- 创作形式：前后对比、家长口述、学生自白、老师视角记录

## 八、核心竞争优势（对竞品打击点）

### vs 国际学校
- 托福雅思难、ALevel/AP难 → 80%学生陪跑，仅20%拿到offer
- 一年20万学费只是表面 → 补课费、考试费、夏校加起来比学费还高
- 师资注水、假外教、管理混乱

### vs 中外合办
- SQA 3+1：最高QS285萨里大学，雅思需过4.5，考不过退学/重读，花费70万+
- 中外2+2：2200个项目，中留服报备仅57个，踩雷率97.41%，花费110万+
- 中外1+3：花费150万+

### vs 传统留学中介
- 行业99%只管"入学"，老席管"毕业"
- 纯中介模式：签证/文书额外收费；老席：全含
- 纯中介无境外老师；老席：50人新加坡团队驻扎
- 纯中介无自持公寓；老席：200套自持

### vs 低价竞品（5.8万）
- 5.8万只是学费 → 加注册费+服务费+预科费实际11.8万+
- 无境外老师，无真实陪跑，仅话术模仿
- 自称"校方"贬低我方为"中介"

## 十、内容避坑指南（合规红线）

- 不夸大：不说"保录取""保毕业"，表述为"毕业率99%（出勤率达标前提下）"
- 不泛化：强调"适合特定学生群体"，而非"适合所有孩子"
- 不虚构：所有案例必须是真实学生
- 不误导：价格要准确 — "国内8万/年，新加坡20万/年，三年总计65万"
- 不越界：只说"新加坡留学"，不混入英美澳加
- 不假承诺：不说"绝对""100%""确保"，用"大概率""99%""过往数据"
- 广告投放注意：不说"包拿毕业证"，改用"捷径""确定性路径""全程陪跑"

## 十一、创始人故事（真诚型内容来源）

- 军人家庭出身，父亲管教严格，形成严谨务实的性格
- 自己作为留学生在新加坡经历了"前三个月没来月经"的极端压力

- 2013年回国创立"不一样的留学"：不管成本多大，都要做一条龙一站式全程陪跑到毕业
- 价值观金句："LX = 良心两个字的首拼"
- 品牌Slogan："培养身心健康、阳光自信、成绩优秀的孩子"
